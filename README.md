# Galaxy Tone 私人色調相機

可在 iPhone Safari 使用的網頁相機（PWA），以三星手機常見的鮮明、通透色彩傾向為靈感，**非三星官方 App**。

## 功能
- Safari 開啟相機、預覽濾鏡、拍照與分享／儲存
- Galaxy 鮮明、Galaxy 自然、水域校色、通透清晰、原始色調
- 從手機匯入舊照片並套用濾鏡
- 所有圖片在裝置上處理，不會自行上傳至伺服器

## 安裝
1. 在本專案 `Settings → Pages`，將 `Source` 設為 **Deploy from a branch**、`Branch` 設為 **main**、`Folder` 設為 **/(root)**，再儲存。
2. 等候 GitHub Pages 完成發布，打開 `https://i9517531-hash.github.io/galaxy-tone-camera/`。
3. 使用 iPhone 的 **Safari** 開啟，選擇分享按鈕 → **加入主畫面**。
4. 首次拍照按「開啟相機」，允許存取鏡頭。

## 限制
- Web 相機的解析度與色彩處理受 Safari 裝置支援影響，無法保證原生相機拍攝品質或完整複製三星原廠 HDR。
- 若分享選單沒有「儲存影像」，可先下載 JPG 再由 iPhone 照片／檔案操作。
- GitHub 儲存庫會公開程式碼，但 App 不會自行上傳相片。
